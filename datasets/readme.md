# PIADE DATASET

PIADE (Packaging Industry Anomaly DEtection) dataset is a dataset produced by GALDI and it contains data from 5 industrial packaging machines.

- Folder `PIADE` containts the PIADE dataset.
- Folder `real` contains the Real World datasets used in the  `EXIFFI` paper that will be used here for tests.
